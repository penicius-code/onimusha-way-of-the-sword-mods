# Katana Stays Sheathed

This mod lives in its own repository: **[onimusha-katana-stays-sheathed](https://github.com/penicius-code/onimusha-katana-stays-sheathed)**.

Two scripts that keep the katana in its sheath after using the bow (Bow Keeps Sheathed) and during wall runs (Wall Run Keeps Sheathed). Single-player only.

| | |
|---|---|
| Requires | REFramework |
| Latest version | Bow Keeps Sheathed 3.1, Wall Run Keeps Sheathed 1.3 |
| Status | Bow Keeps Sheathed 3.0 worked in game on 2026-11-13; 3.1 passes its offline test but was not re-tested in game. Wall Run Keeps Sheathed confirmed working in game on 2026-11-15. |

Published on Nexus Mods as "Katana Stays Sheathed - Bow and Wall Run": <https://www.nexusmods.com/onimushawayofthesword/mods/401>

There is no code in this folder. Install, uninstall, compatibility and known issues are in the [standalone README](https://github.com/penicius-code/onimusha-katana-stays-sheathed#readme).
